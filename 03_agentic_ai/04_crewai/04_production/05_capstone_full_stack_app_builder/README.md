# Module 05 - Capstone: Full-Stack App Builder

> **MLCourse - Production Readiness - Capstone: Full-Stack App Builder**

The final capstone brings everything together: build a full-stack application using
CrewAI agents that plan, code, test, and deploy. This module exercises every skill
from the track in a realistic, end-to-end project.

## What you'll learn

- Design a multi-agent system for a real-world application
- Combine agents, tasks, tools, knowledge, memory, and Flows
- Implement testing, observability, and production patterns
- Build a working application from specification to deployment
- Debug and iterate on complex multi-agent workflows

## Key concepts

- **Full-stack agent system**: agents that plan, code, test, and deploy
- **End-to-end workflow**: from requirements to running application
- **Production patterns**: testing, monitoring, error handling in practice
- **Agent collaboration**: multiple specialized agents working toward one goal
- **Capstone integration**: everything from the track in one project

## Contents

1. `01_capstone_spec.ipynb` - project requirements, agent roles, workflow design
2. `02_capstone_build.ipynb` - implementing the agent crew and flow
3. `03_capstone_test.ipynb` - testing, evaluation, iteration
4. `04_capstone_deploy.ipynb` - final polish, deployment considerations

Congratulations on completing the CrewAI track! You now have the skills to build
production-grade multi-agent systems with role-based agent teams.
