This project is a full-stack Todo application designed for tracking tasks, allowing users to create, filter, update, and delete items through a simple interface. The tech stack consists of a RESTful API backend managing a relational database and a component-based frontend built with interactive UI elements for form submission and list rendering. To run the application, clone the repository, install dependencies for both the backend and frontend, start the database server, and execute the development servers for the API and UI.
