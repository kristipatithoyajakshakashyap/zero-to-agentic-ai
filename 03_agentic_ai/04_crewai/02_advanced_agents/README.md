# Advanced Agent Features

Extend CrewAI agents beyond the basics: custom tools, knowledge ingestion, memory
systems, reasoning strategies, and multimodal capabilities that let agents
interact with more than just text.

## Modules

| Folder | Teaches |
|---|---|
| [01_custom_tools](./01_custom_tools/README.md) | @tool decorator, BaseTool subclass, error handling |
| [02_knowledge_sources](./02_knowledge_sources/README.md) | Text/PDF knowledge, agent vs crew knowledge |
| [03_memory_systems](./03_memory_systems/README.md) | Short-term, long-term, entity memory |
| [04_reasoning_and_planning](./04_reasoning_and_planning/README.md) | Chain-of-thought, crew planning |
| [05_conditional_and_multimodal](./05_conditional_and_multimodal/README.md) | ConditionalTask, VisionTool, DALL-E |

## Prerequisites

Complete the **CrewAI Fundamentals** category first. Agents, tasks, and processes
are assumed knowledge.
