# CrewAI Fundamentals

The foundation of multi-agent systems with CrewAI: installation, agent roles and
goals, task definitions, process orchestration, built-in tools, and a mini-capstone
that ties it all together into a working research crew.

## Modules

| Folder | Teaches |
|---|---|
| [01_installation_and_first_crew](./01_installation_and_first_crew/README.md) | pip install, CLI scaffolding, first crew from scratch |
| [02_agents_deep_dive](./02_agents_deep_dive/README.md) | Agent role, goal, backstory, LLM assignment, delegation |
| [03_tasks_and_processes](./03_tasks_and_processes/README.md) | Task descriptions, sequential vs hierarchical, async kickoff |
| [04_built_in_tools](./04_built_in_tools/README.md) | FileReadTool, ScrapeWebsiteTool, SerperDevTool catalog |
| [05_research_assistant_crew](./05_research_assistant_crew/README.md) | Mini-capstone: research crew that searches, reads, and reports |

## Prerequisites

Complete **LangChain Fundamentals** recommended. Familiarity with Python, chat
models, and basic prompt engineering is assumed.
