# Module 08: Travel Planner

> **MLCourse - Agentic AI - Multi-Agent + Human-in-the-Loop**

Build a multi-agent travel planning system that coordinates specialized agents for research, itinerary design, and budgeting, with human-in-the-loop approval gates at critical decision points.

## Notebooks

| # | Notebook | Focus |
|---|----------|-------|
| 01 | [01_travel_planner_setup](01_travel_planner_setup.ipynb) | Agent orchestration framework and multi-agent communication setup |
| 02 | [02_research_agent](02_research_agent.ipynb) | Destination research agent for attractions, weather, and local info |
| 03 | [03_planning_agent](03_planning_agent.ipynb) | Itinerary construction agent with scheduling and budget optimization |
| 04 | [04_hitl_approval](04_hitl_approval.ipynb) | Human-in-the-loop approval workflow for itinerary review and editing |

## Prerequisites

- Modules 02-07 (Agent architectures, tool use, orchestration patterns)

## When to use this technique

- Multi-step workflows requiring specialized sub-agents to handle distinct domains
- Applications where human oversight is needed before finalizing high-stakes outputs
- Systems that combine automated research with constrained planning logic
- Projects demonstrating agent collaboration and delegation patterns
