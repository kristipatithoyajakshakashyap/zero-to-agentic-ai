# LangGraph - Graph-Based Agents

Move beyond linear chains into stateful, graph-based agent workflows with
LangGraph. Learn to model branching logic, cycles, and human-in-the-loop
interactions as explicit state machines - building toward multi-agent
orchestrations that can reason, act, and self-correct.
