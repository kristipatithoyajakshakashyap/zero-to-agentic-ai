# Module 19: Capstone — LinkedIn Research Post Generator

> **MLCourse - Agentic AI - LangGraph**

A complete end-to-end capstone project that brings together every LangGraph concept into a multi-agent system that researches a topic and publishes a polished LinkedIn post using Playwright.

- How to architect a multi-agent system from scratch for a real-world use case
- How to combine tool-using agents, persistence, human-in-the-loop, and streaming into one pipeline

- How to structure, debug, and polish a production-quality agentic workflow
