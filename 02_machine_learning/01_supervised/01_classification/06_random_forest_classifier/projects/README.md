# Random Forest Classifier - Projects

**MLCourse · Machine Learning · projects/** - 3 real datasets, rising difficulty.
Every project re-runs a task you have already solved with a single model, so
you can see exactly what the ensemble buys you - and what it costs.

| # | Difficulty | Dataset | Skills spotlight |
|---|---|---|---|
| 01 | Easy | `penguins.csv` | forest vs the lone tree from module 05: does it win, and do their importances agree? |
| 02 | Medium | `heart.csv` | recall on the disease class via `class_weight` plus a threshold policy, then a permutation-importance audit |
| 03 | Hard | `german_credit.csv` | OOB validation, one-hot pipeline inside the forest, permutation audit, and the dollar ledger from the SVM module for comparison |

## Rules of engagement

- Attempt each phase before reading the next cell.
- Restart kernel & run all cells before declaring victory.
- Add ONE analysis question of your own to every project.
- Grade with the rubric in the module README one level up.

Datasets live in the shared `02_machine_learning/data/` folder; anything missing is downloaded once on first run and cached there. Start at Project 01!
