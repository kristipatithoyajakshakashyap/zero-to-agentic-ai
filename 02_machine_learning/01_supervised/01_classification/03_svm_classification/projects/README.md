# Support Vector Machines (Classification) - Projects

**MLCourse · Machine Learning · projects/** - 3 real datasets, rising difficulty.
Every project: business question -> EDA -> prep -> kernel and C/gamma search
-> evaluation -> findings. Watch the margin, not just the accuracy.

| # | Difficulty | Dataset | Skills spotlight |
|---|---|---|---|
| 01 | Easy | `penguins.csv` | draw the linear-SVM margin street on a separable pair, then stress it on the overlapping Chinstrap/Adelie pair with an RBF kernel |
| 02 | Medium | `heart.csv` | kernel shootout under a proper grid, then bend the decision threshold into a screening posture |
| 03 | Hard | `german_credit.csv` (OpenML `credit-g`) | mixed-type preprocessing, then pricing the confusion matrix in dollars and moving the operating point until profit stops improving |

## Rules of engagement

- Attempt each phase before reading the next cell.
- Restart kernel & run all cells before declaring victory.
- Add ONE analysis question of your own to every project.
- Grade with the rubric in the module README one level up.

Datasets live in the shared `02_machine_learning/data/` folder; anything missing is downloaded once on first run and cached there. Start at Project 01!
